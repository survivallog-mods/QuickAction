# 更新日志（SurvivalLog.QuickAction / 动作提速）

> 本文件只记本 mod 的更新；套件/安装器版本史见总仓根 CHANGELOG.md。
> 版本号单源：总仓 version.json 的 mods 字段（作者定义）。

## v1.8.1（2026-11-15，配置清单内嵌——配合 MOD 管理中心 v2.2.1）

- **优化**：内嵌 mcSpec 2 配置清单——管理中心面板的配置页改由本 mod 自带清单驱动，配置项增删改面板自动跟上；玩法与配置项零变化。

## v1.8.0（2026-11-08，面板动作目录——配合 ModCenter v2.0.7 覆盖下拉）

- **新增 `BepInEx\QuickActionCatalog.txt`**：每会话表就绪后写一次（先于首次 Apply，期间
  During 还是官方原值）。行格式 `ID|名称|分类|原耗时毫秒`（分类 1物品使用 2家具功能
  3房屋维护 4杂项交互 5娱乐锻炼 **6野外与其他**），口径=Apply 覆盖分支的全部前置守卫 +
  分类并集——表外结算收益/周期正收益/纯消耗拦Outside8/瞬时哨兵/禁改类（睡觉·社交）/
  无名行全剔除，**列进来的动作覆盖一定生效**。
- **第 6 组「野外与其他」（作者令：野外探险必须在列）**：引用轴（家具按钮/物品使用引用）
  收不到的 Other(8) 玩家动作——典型：冒险出门 探索中109、搜索1506/1103、翻找1505/1503、
  强行开启1103、撬开1930/1929…、瞭望114、清点物资115、修复记录仪211、清理障碍202 等，
  由探索/场景系统 BT 触发，五分类结构性漏掉；Overrides 兜底分支先于分类判定，对它们照常
  生效（只是吃不到分类开关，面板逐条调）。同桶会进少数内部行为（呕吐/行为N/测试）——
  名字可见玩家自辨，不触发无副作用。**禁改类（睡觉/社交）仍不进目录。**
- 消费方：ModCenter v2.0.7 面板「动作覆盖」新增行走二级分组下拉（optgroups 类型→动作），
  选项只显示**动作名**，玩家不再需要懂 ID（作者令）。"哪些动作可加速"的口径单源在本 mod，
  ModCenter 只读不复算，守卫口径随本 mod 迭代自动跟进。
- 引擎/配置/兼容性零改动：老 cfg 照读；总开关关闭的会话不写目录（面板读到旧文件照常展示；
  首次运行就关机的极端场景无文件，面板回退 ID 手输框）。
- **部署注意**：面板下拉要出全量名单，必须 ModCenter 与 QuickAction **两个 dll 都换新**并
  重启——旧 QuickAction（1.7.0）不产目录文件，面板回退 ID 手输框；判断标志 =
  `BepInEx\QuickActionCatalog.txt` 是否生成。
